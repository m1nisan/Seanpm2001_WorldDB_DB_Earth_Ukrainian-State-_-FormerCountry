After installation, you can use the database for various applications. Here are some examples:

## 📑 Data Structure

The database contains multiple tables, each representing different aspects of the Ukrainian State. Here’s a brief overview:

- **Geography Table**: Contains data on geographical features, such as mountains, rivers, and cities.
- **History Table**: Includes significant historical events, dates, and descriptions.
- **Culture Table**: Features cultural aspects, including traditions, languages, and notable figures.
